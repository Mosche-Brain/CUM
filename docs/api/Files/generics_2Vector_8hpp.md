## Detailed Description

Templated generic vector class supporting both fixed compile-time and dynamic dimensions. 

**Author**: jaro


Provides generic vector arithmetic, dot/cross products, normalization, and predefined aliases (ivec2-4, fvec2-4, dvec2-4, hvec2-4).
