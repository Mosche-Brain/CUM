# CUM Modules

CUM is organized into modular subsystems tailored for high-performance numerical workloads.

- [**Core & Memory**](core.md): Unified memory handlers, allocations, views, and containers (`Vector`, `Matrix`, `Tensor`).
- [**LARA (BLAS)**](lara.md): Linear algebra routines covering Level 1, 2, and 3 operations.
- [**Neural Primitives**](neural_primitives.md): Deep learning operators, memory descriptors, and oneDNN execution engines.
- [**Elementwise Functions**](functions.md): Math primitives, activation functions, and transformations.
