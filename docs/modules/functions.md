# Elementwise Functions

Header: `<cum/functions.hpp>`

The Functions module supplies highly optimized vectorized and GPU-accelerated mathematical operations.

## Categories

- **Activations & Logistic**: `sigmoid`, `relu`, `gelu`, `tanh`, `swish`
- **Trigonometric & Cyclometric**: `sin`, `cos`, `tan`, `asin`, `acos`, `atan`
- **Hyperbolic**: `sinh`, `cosh`, `tanh`, `asinh`, `acosh`, `atanh`
- **Exponential & Power**: `exp`, `log`, `log2`, `log10`, `pow`, `sqrt`, `rsqrt`
- **Linear Units**: `leaky_relu`, `elu`, `selu`
